# Source Citations

## Purpose

Answers should be traceable to source records.

## Source Reference Format

Each returned record should include:

- source
- source_record_id
- title
- timestamp
- url if available
- last_synced_at

## Answer Rule

When giving factual answers from personal data, include source references internally.

UI should eventually show:

- source app
- record title
- last synced time
- link to original record if available

## Stale Data

If a source has not synced recently, answers must mention that the data may be stale.
