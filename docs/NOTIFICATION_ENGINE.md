# Notification Engine

## Purpose

Proactively surface useful information.

## MVP Notifications

- event starting soon
- deadline due today
- deadline due tomorrow
- schedule conflict
- failed sync
- stale data warning

## Notification Channels

MVP:

- terminal/desktop notification
- app UI notification

Future:

- email
- SMS
- mobile push
- Discord/Slack DM

## Notification Rules

- avoid spam
- respect quiet hours
- group related alerts
- include source
- include timestamp
- include action suggestion when useful

## Daily Briefing

Default morning briefing should include:

- today's schedule
- tomorrow's major deadlines
- conflicts
- important unread emails
- stale sync warnings

## Evening Recap

Future recap can include:

- completed events
- missed deadlines
- tomorrow prep
- unread important updates
