# Permissions

## Principle

Read-only first.

The system should never perform write actions without explicit user confirmation.

## MVP Permissions

### Google Calendar

Read calendar events only.

### Outlook

Read calendar events.

Optional:

- read recent mail summaries

### D2L/Brightspace

Read courses, calendar items, and deadlines only.

## Future Permission Levels

### Level 1: Read

Can read and summarize data.

### Level 2: Draft

Can draft actions but not execute them.

Examples:

- draft email reply
- draft schedule change
- draft task plan

### Level 3: Confirmed Write

Can execute only after explicit approval.

Examples:

- create calendar event
- send email
- mark task complete

### Level 4: Autonomous Write

Not allowed until system is mature and safe.
